2. What the deliverable is

Each assignment is a single self-contained HTML page that looks like handwritten blue-ink text on ruled notebook paper, with a red margin rule, and prints cleanly to A4.

3. Standard workflow

  1. Get the content. ChatGPT share links will not load — they need JavaScript and only return the title. Ask the user to paste questions and answers as text.
  2. Read source files. .docx is a ZIP: unzip word/document.xml and strip tags. Scanned .pdf has no text layer — extract the embedded JPEGs and read them as images.
  3. Reuse the template from experiment-05.html. Do not restyle from scratch.
  4. Write the HTML, then verify (section 7).
  5. Deliver and tell the user how to print.

4. Required CSS core

@font-face {
  font-family: 'Wraith Ink';
  src: url('wraith-ink-sonata-regular.ttf') format('truetype');
}
body {
  font-family: 'Wraith Ink', cursive;
  color: #15249b;                 /* blue ink */
  -webkit-print-color-adjust: exact;
  print-color-adjust: exact;      /* rules must survive printing */
}

/* Ruled paper: red margin rule + 32px blue lines */
.sheet {
  width: 210mm;
  background-color: #fffdf7;
  background-image:
    linear-gradient(90deg, transparent 21mm, rgba(230,60,60,.65) 21mm,
                    rgba(230,60,60,.65) 21.6mm, transparent 21.6mm),
    repeating-linear-gradient(to bottom, transparent 0, transparent 31px,
                    rgba(60,140,220,.45) 31px, rgba(60,140,220,.45) 32px);
  padding: 32px 12mm 32px 25mm;   /* all multiples of 32px */
  line-height: 32px;              /* one line of text per rule */
  min-height: 297mm;
}

/* CRITICAL: ink must sit ON the line, not float above it */
h2.q, h3, p, li, .title, .code, td, th {
  position: relative;
  top: 7px;
}

@page { size: A4; margin: 0; }
@media print {
  body { background: #fff; }
  .toolbar { display: none !important; }
  .sheet { width: auto; margin: 0; box-shadow: none; padding: 12mm 10mm 12mm 24mm; }
}

Why line-height: 32px matters

The rules repeat every 32px. Text line-height must equal 32px and the sheet padding must be a multiple of 32px, or every line drifts off its rule. Block spacing should also be multiples of 32 (use margin: 32px 0 0 0, not 16px).

Why top: 7px matters

Handwriting fonts have large ascender space, so text baseline lands above the rule and looks like it is floating. Shifting every text block down 7px seats it on the line. If it still looks off on the user's screen, nudge to 9px — do not remove it.

6. Humanistic errors (make it look real)

Deliberate, light imperfection. Too many looks fake; too few looks printed.

TypeMarkupExamples used
Struck-out correction <span class="cross">typo</span> fixedword resorces resources · machinary machinery · similiar similar
Ink smudge <span class="smudge"></span> Place once or twice per assignment, near the end of a paragraph.
Plain misspelling write it directly seperating, occuring, tranportation, temprature, sulpher, maintanance, managment 
.cross { text-decoration: line-through; text-decoration-thickness: 2px; }
.smudge {
  display: inline-block; width: 14px; height: 10px;
  background: radial-gradient(ellipse at center, rgba(21,36,155,.55) 0,
              rgba(21,36,155,.25) 60%, transparent 70%);
  border-radius: 50%; vertical-align: baseline; margin: 0 2px;
}

Target per assignment

2–3 struck corrections · 1–2 smudges · 2–4 plain misspellings. Never corrupt formulas, code, variable names, or numerical answers.

7. Before you deliver

  1. Font path resolves relative to the HTML file — keep both files in the same folder.
  2. No raw < inside <pre> blocks (use &lt;).
  3. Count <u> tags — should be near zero.
  4. If output examples are shown, verify them by hand or by running the code.
  5. Open the page, hard-refresh, and eyeball that text sits on the rules.

8. How the user prints

  1. Open in Chrome or Edge.
  2. Click the Print Assignment button in the top toolbar.
  3. Set Paper: A4 Margins: None and enable Background graphics — without it the ruled lines and red margin will not print.
  4. Print or Save as PDF.

Quick start for the next assignment

  1. Copy experiment-05.html to a new file.
  2. Swap the heading to Assignment - 0N and replace the body with the new content.
  3. Keep the CSS core untouched, apply the humanistic errors, then run section 7.
